# Лабораторная работа №1. Статическая клиентская часть веб-приложения (Аминов А.А. ИВТ-ИСУ-302Б)

## О проекте

**PC Parts** — статический каталог компьютерных комплектующих:
процессоров, видеокарт, материнских плат и оперативной памяти.
Страница показывает карточки с ключевыми характеристиками и
предлагает форму фильтрации и конструктор сборки ПК.

Проект создан как **первый этап** веб-приложения. 

## Для кого предназначен

Проект рассчитан на **одну категорию пользователей**:

- **Сборщики ПК** — люди, которые хотят собрать себе новый компьютер и
ищут удобный сайт для этого удобный сайт. Наше приложение им точно поможет подобрать лучшие комплектующие,
а также ускорит время поиска товара.

| Блок | Тег | Содержание |

## Используемые технологии

#### Где используется Grid

- **`.cards-grid`** — сетка карточек каталога:
  `display: grid; grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`.
  Автоматически 1/2/3 колонки в зависимости от ширины экрана.
- **`.builder-form`** — группы полей конструктора сборки:
  `display: grid; grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`.
  Поля встают в 2–3 колонки на широком экране.
- **`.builder-group--wide`** — группа с `<textarea>`:
  `grid-column: 1 / -1` — растягивается на всю ширину сетки.

#### Где используется Flexbox

- **`.header-inner`** — шапка: логотип слева, меню справа
  (`justify-content: space-between`).
- **`.main-nav ul`** — пункты меню в одну строку.
- **`.filter-form`** — поля формы фильтрации в ряд с переносом
  (`flex-wrap: wrap`).
- **`.card`** — карточка: картинка сверху, текст снизу
  (`flex-direction: column`).
- **`.card-meta`** — характеристики комплектующего в столбик.
- **`.builder-actions`** — две кнопки конструктора в ряд.
